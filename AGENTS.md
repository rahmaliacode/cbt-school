# CBT School

Use Laravel, MySQL, Blade, and local assets only. Tables, columns, model names, and code identifiers are English. Interface text is Indonesian.

Preserve the server-authoritative session deadline, immutable session snapshots, one attempt per participant/session, transaction lock order (session then attempt), idempotent submit, and monitor privacy. Question/option IDs, not display letters, determine scoring. Never commit credentials or participant data.

Validate changes with `php artisan test`, `php artisan view:cache`, and syntax checks. Use MySQL for deployment and database integration tests. Document any verification limits. No frontend build is required.
